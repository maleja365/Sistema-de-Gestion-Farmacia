 ## FarmaciApp
Sistema de gestión y domicilios para farmacias, desarrollado en Java. Permite a los clientes pedir productos a domicilio y a los empleados administrar el catálogo de productos mediante un CRUD completo.

## Objetivo
FarmaciApp busca digitalizar la operación de una farmacia, conectando a los clientes con los productos disponibles y permitiéndoles realizar pedidos a domicilio de forma fácil y rápida. Al mismo tiempo, brinda a los empleados una herramienta de administración para gestionar el inventario de productos que los clientes visualizan en la aplicación.

## Funcionalidades principales

### Cliente
- Registro e inicio de sesión con autenticación segura
- Visualización del catálogo de productos disponibles
- Solicitud de pedidos a domicilio
- Seguimiento de sus pedidos

###  Empleado
- Inicio de sesión con rol diferenciado
- **CRUD completo de productos:**
  - Crear nuevos productos con nombre, descripción, precio e imagen
  - Listar todos los productos del catálogo
  - Editar información de productos existentes
  - Eliminar productos del catálogo
  - Gestión de pedidos entrantes a domicilio
